## Overview

**Internet Status** announces your current network and internet connection status on Windows 10 and Windows 11, lets you open the Windows network menu, and can speak and copy the password of your connected Wi-Fi network.

## Shortcut Key

Default shortcut: `NVDA+Alt+i` (customizable via NVDA Menu > Preferences > Input Gestures > Internet Status).

* **Press once (`NVDA+Alt+i`):** Announces all currently connected networks and whether each has *Internet access* or *No internet access*.
* **Press twice quickly:** Opens the Windows network menu after a brief delay.
* **Press three times quickly:** Speaks the saved password of the connected Wi-Fi network and copies it to the clipboard.

## Notes

* Password retrieval works only for Wi-Fi networks that have a saved security key (not Ethernet/LAN or networks without stored passwords).
* Pressing three times speaks the password aloud and copies it to the Windows clipboard, so keep your surroundings and clipboard history in mind.
